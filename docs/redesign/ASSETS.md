The finite allowlist is `server/content/collection.js`. Each delivered fact retains its source link; an original drawing prompt is labeled as a prompt, not a sourced fact. Selection reuses the existing date seed and shown-item history. No live feed or AI writer participates.

- **Maomao:** 11 selected existing entries, including two explicitly sealed manga notes; no light-novel-only entries. Character names, voices and release information checked against [Crypton’s character profiles](https://piapro.net/intl/en_character.html); event/song details checked on the two official SNOW MIKU pages above. These are selected listens, not claimed personal favorites.
- **Cosplay:** four selected notes. Wrap-skirt overlap from SajaLyn’s own account; detangling from [Arda’s FAQ](https://arda-wigs.com/pages/faq); reusable scraps from [Worbla](https://www.worbla.com/?p=863); repair-kit reference from [Punished Props](https://www.punishedprops.com/2014/07/29/prop-shop-cosplay-repair-kit/). No budget, checklist or shopping feed.
- **Art:** selected existing drawing principles, three explicit OC prompts and filtered subject/twist combinations. Procreate masking notes link to the [official handbook](https://help.procreate.com/procreate/handbook/layers/layers-mask). General drawing suggestions carry no fabricated external attribution.
